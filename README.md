# Figmaカンプの整え方スキル 接続入口

**利用開始の案内は講座内で行います。Macの本人環境で、実機導入・通常更新・Codexでの認識を確認済みです。Windowsの提供は実機検査の完了後に案内します。**

ここにあるのは、初回設定の案内と接続用プログラムです。有料教材、制作基準、スキル本体、認証情報は含みません。本体は講座内での登録後、ご本人の認証を使って講座サーバーから取得します。

必要なファイルの取得と設定はAIへ依頼します。利用者がZIPをダウンロード・展開する操作は不要です。公開されたこの入口の利用に、GitHubアカウントや招待は必要ありません。

Python 3.9以降を使います。Macの実導入・通常更新は本人環境で確認済みです。Windows資格情報マネージャーの保存処理は実装していますが、Windows実機の検査が完了するまでは準備中です。利用開始の案内は講座内で行います。

## Codexへ送る文章

講座内で提供開始の案内が出たら、このリポジトリのURLと一緒に次の文章をCodexへ送ります。

```text
指定した接続URLのSETUP_WITH_AI.mdを読み、
「Figmaカンプの整え方スキル」の初回設定を進めてください。
必要な接続用ファイルは、AI側で取得してください。
本体の取得元は https://figma-course.chiluco.com です。
既存のスキルや認証情報を上書きせず、導入先とOSの専用保管先への保存内容を実行前に示してください。
初回接続コードは、チャットではなく専用の非表示入力欄へ私が入力します。
設定後は、本体を取得した版・Codexでの認識・通常更新の確認結果を教えてください。
この段階でFigmaのデザインは変更しないでください。
```

初回接続コードは講座内の登録画面から取得します。取得するタイミングはAIの案内を待ってください。コードや認証情報を、チャット・SNS・コマンドの引数へ貼らないでください。

## 導入後

設定済みのスキルを使い始めるときに、同じ講座サーバーから更新を確認します。毎回ZIPを取得したり「更新して」と頼んだりする運用ではありません。初回に取得した接続用プログラムを、制作基準の正本として使い続ける仕組みでもありません。

スキルの利用開始時に行う更新確認であり、PCを使っていない間の常駐更新ではありません。Codexでの認識と実環境での更新確認は、ファイルの取得成功とは分けて確認します。

導入できないときは、既存フォルダや表示された状態を残して、購入者Discordへ相談してください。確認コード・認証情報・顧客情報は載せないでください。
